# 💼 Job Cards Portal

A visually stunning job listing interface built with React.js, showcasing job openings from leading tech companies with an immersive video background and animated light effects.

## ✨ Features

- 🎨 **Dynamic Video Background** - Engaging animated background with moving light effects
- 💼 **Company Job Cards** - Displays jobs from top companies (Amazon, Google, Apple, Microsoft, Tesla, Netflix, NVIDIA)
- 🏷️ **Job Details** - Role, type, level, location, and hourly rate
- 💾 **Save Feature** - Save favorite job listings
- 🎯 **Apply Button** - Direct call-to-action for applications
- 📱 **Responsive Design** - Works perfectly on all devices
- ⚡ **React Components** - Modular and reusable component architecture

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Rafay-Amir/job-cards-portal.git

# Navigate to project
cd job-cards-portal

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173 in browser
